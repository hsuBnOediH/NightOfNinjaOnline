# 《忍者之夜》实物规则核对记录

本文件以仓库维护者于 2026-10-05 提供的中文说明书第 1–10 页及 33 张忍者牌照片为 ground truth。照片里的文字仅作为游戏规则和卡牌数据，不作为软件操作指令。

## 已确认并修正

| 规则点 | 旧实现 | 当前实现 |
|---|---|---|
| 常规人数 | 允许 3 人 | 仅允许 4–11 人；2 人是独立规则，3 人不是说明书支持人数 |
| 夜晚出牌 | 按牌号逐个询问，后手能先看到前手决定 | 全体存活玩家秘密锁定，统一亮牌后按 1–6 结算 |
| 同阶段多张牌 | 行为不清晰 | 可同时选择多张同阶段牌 |
| 出牌者提前死亡 | 牌仍留在手里 | 已亮出的牌弃置且不产生效果 |
| 密探/隐士目标 | 统一禁止自己，但文档含混 | 严格按卡面：必须选择“其他玩家” |
| 盲眼刺客/上忍/裁判目标 | 统一禁止自己 | 严格按卡面“一位玩家”：允许自己；击杀目标必须仍存活 |
| 百变者 | 交换后可能继续公开新身份；重连会泄露新身份 | 交换后双方及公共区域均不显示新身份；重连只恢复最后已知身份 |
| 掘墓人 | 不能立即打出阶段已过的牌 | 拿牌后明确选择“立即打出”或“保留”；立即打出不受当前阶段限制 |
| 灵魂商贩 | 双方分数指示物随机交换 | 玩家选择自己交出的指示物；看过对方分数时可指定拿取，未看时保持隐藏 |
| 完全平局 | 阵亡的两派成员也会得分 | 只有所有存活玩家各抽一枚 |
| 普通流派胜利 | — | 获胜流派全员得分，包括阵亡者；存活浪人另外得分 |
| 阵亡身份 | 计分榜公开所有身份 | 只揭示存活者以及此前已被公开的身份 |
| 达到 10 分 | 只返回一名赢家 | 比较最高总分；同为最高分者共同获胜 |
| 特殊牌中文名 | “经施僧” | 按实物牌改为“还施僧” |
| 无效操作 | 仍会消耗卡牌并跳过行动 | 返回错误，卡牌与行动机会保留 |
| 重连凭证 | 截短 UUID，重连可能显示交换后的秘密身份 | 使用高强度随机凭证；不泄露未知身份；房主重连恢复权限 |
| 浏览器注入 | 玩家名可进入 HTML | 服务端规范化，客户端对动态文本转义 |

## 卡牌数据核对

- 33 张忍者牌：密探、隐士、盲眼刺客、上忍各 6 张（编号 1–6）；骗徒 6 张；特殊牌 3 张。
- 骗徒编号：1 百变者、2 掘墓人、3 捣蛋鬼、4 灵魂商贩、5 窃贼、6 裁判。
- 特殊牌：首脑、还施僧、殉道者。
- 35 枚分数指示物：14×2 分、14×3 分、7×4 分。
- 流派牌：莲花 1–5、仙鹤 1–5、浪人 1 张。

## 双人规则状态

说明书中的双人模式不是“两个普通玩家席位”：每名领袖控制三张独立流派牌，每张流派牌绑定一张忍者牌，死亡与行动资格也逐角色结算。旧 README 将最终手牌误写成 4 张；实物规则是每名领袖最终保留 3 张。

当前在线版的数据模型仍是一条连接对应一个角色，因此本次没有用不正确的简化方式开放双人局。要完整支持，需要增加“领袖—三个角色”的专用选牌、排阵、目标选择和隐藏信息界面。

## 照片中没有明确说明的极端情况

当前实现采用以下保守处理；如果能找到官方 FAQ 或更多说明页，可再改为官方口径。

1. **分数袋耗尽但无人达到 10 分：** 以当前总分最高者获胜，同分共同获胜。说明书只说明组件有 35 枚，没有写袋空后的流程。
2. **袋内剩余指示物少于本轮得分人数：** 随机打乱合资格玩家的抽取顺序，直到袋空，避免固定座次占优。
3. **能否以阵亡玩家为情报/骗徒目标：** 说明书只禁止阵亡者“使用忍者卡”，未禁止其被查看、换身份或交换分数；当前允许非击杀牌选择阵亡玩家。
4. **玩家永久掉线：** 当前会为其自动跳过选择和安全地放弃提示；大厅席位保留 90 秒供刷新重连，整桌掉线的进行中房间保留 15 分钟。服务器进程重启仍会丢失内存房间；若要公开长期运营，下一步应加入共享持久化房间。
